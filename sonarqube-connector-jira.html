SonarQube Connector for Jira



Conecta SonarQube Server o SonarQube Cloud con Jira para consultar la calidad de tu código, crear tareas y generar informes PDF desde tus proyectos.

Accede a las métricas y al estado del Quality Gate sin salir de Jira. Convierte los hallazgos de SonarQube en tareas para gestionar su resolución y comparte los resultados del análisis mediante informes PDF.

PRUEBA GRATIS

Qué puedes hacer con SonarQube Connector for Jira

Reúne la información de calidad del código y la gestión del trabajo en Jira. El conector ayuda a desarrolladores, equipos de calidad y responsables de ingeniería a consultar los resultados de SonarQube y utilizarlos para organizar las mejoras del software.

Consulta las métricas de SonarQube desde Jira

Visualiza el estado del Quality Gate, las métricas de calidad y los detalles de los problemas detectados en tus proyectos de SonarQube Server o SonarQube Cloud.

Consulta la información de calidad y seguridad del código desde Jira para identificar qué aspectos necesitan atención y decidir qué trabajo abordar.


Cómo generar un informe PDF de SonarQube desde Jira Cloud →

Genera informes PDF de SonarQube desde Jira

Exporta los resultados de uno o varios proyectos de SonarQube a un informe PDF para compartirlos con tu equipo, responsables de proyecto o clientes.

El conector permite generar estos cinco tipos de informes: informe general de calidad, CWE Top 25, OWASP Top 10, OWASP ASVS e ISO 5055.

Utiliza los informes para comunicar el estado de tus proyectos y aportar información a las revisiones de calidad y seguridad.

Crea tareas en Jira a partir de los hallazgos de SonarQube

Crea una tarea de Jira con un clic a partir de un problema detectado por SonarQube. Lleva los hallazgos al proyecto donde tu equipo organiza el trabajo para priorizar su resolución.

Esta función facilita el seguimiento de las correcciones y evita copiar manualmente la información entre herramientas.



Consulta varios proyectos con Project Portfolio

Vincula varios proyectos de SonarQube a un proyecto de Jira mediante Project Portfolio.

Esta función resulta útil cuando tu equipo gestiona varios componentes de software desde un mismo proyecto de Jira y necesita consultar sus resultados de calidad en un único lugar.

Preguntas frecuentes

¿El conector funciona con SonarQube Server y SonarQube Cloud?

Sí. SonarQube Connector for Jira permite integrar proyectos de SonarQube Server y SonarQube Cloud con Jira.

¿Puedo descargar informes PDF de SonarQube desde Jira?

Sí. El conector permite generar informes PDF con los resultados de tus proyectos, incluidos el informe general de calidad y los informes relacionados con CWE Top 25, OWASP Top 10, OWASP ASVS e ISO 5055.

¿Puedo trabajar con varios proyectos de SonarQube?

Sí. Project Portfolio permite vincular varios proyectos de SonarQube a un proyecto de Jira. También puedes generar informes PDF para uno o varios proyectos.

¿Las tareas se crean automáticamente?

La creación se inicia mediante una acción del usuario: puedes crear una tarea de Jira con un clic a partir de un hallazgo de SonarQube.

¿Dónde puedo consultar los precios y probar la aplicación?

En la ficha de SonarQube Connector for Jira en Atlassian Marketplace puedes consultar los precios y las opciones de prueba disponibles.
