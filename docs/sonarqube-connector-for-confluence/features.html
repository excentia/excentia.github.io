Funcionalidades

SonarQube Connector for Confluence muestra en tus páginas de Confluence los resultados de calidad y seguridad del código de SonarQube Server o SonarQube Cloud. Puedes revisar el Quality Gate de un proyecto antes de una entrega, seguir varios componentes en una sola vista o añadir un badge de cobertura a la página de un componente.

Comprueba el Quality Gate antes de una entrega

Muestra el estado del Quality Gate y sus condiciones en una página de Confluence. Al revisar una entrega, consulta las condiciones para identificar qué debes corregir si un proyecto no supera el Quality Gate.

Añade un panel de proyecto a una página de Confluence

Usa SonarQube Connector Macro para mostrar las calificaciones de fiabilidad, seguridad y mantenibilidad de un proyecto junto con métricas como la cobertura, la duplicación de código y la deuda técnica. Selecciona una conexión de SonarQube configurada e introduce la clave del proyecto en Resource Key. En Custom metrics, añade las claves de las métricas que quieras mostrar. Si configuras la macro para un único proyecto, también puedes indicar una rama.

Consulta la guía de configuración de la macro.

Consulta varios proyectos de SonarQube en una misma vista

Introduce varias claves de proyecto separadas por comas en Resource Key o selecciona proyectos por sus etiquetas de SonarQube en Tags. La macro muestra las métricas y calificaciones agregadas, el estado del Quality Gate y la fecha del último análisis de cada proyecto. Si tu edición lo admite, también puedes seleccionar un portfolio de SonarQube Enterprise por su nombre.

Consulta cómo configurar varias claves de proyecto y usar etiquetas y portfolios.

Muestra una métrica de SonarQube como un badge

Usa SonarQube Connector Badge si necesitas mostrar una sola métrica en la página. Selecciona la conexión de SonarQube, introduce la clave del proyecto y elige la métrica en Metric Key. La macro también permite agregar una misma métrica de varios proyectos.

Por ejemplo, introduce sonarlint-visualstudio en Resource Key y coverage en Metric Key. Coloca el badge junto al resumen del componente para que quien consulte la página vea la cobertura al abrirla. Configuración del badge · Ejemplos de badge.

Revisa incidencias y hallazgos de seguridad

Muestra un desglose de incidencias de SonarQube

Usa Issue Breakdown para mostrar un resumen de las incidencias de uno o varios proyectos. Así, el equipo puede revisar las incidencias junto con la documentación del proyecto.

Muestra informes de seguridad

Usa estas macros para añadir los hallazgos de SonarQube a una página de revisión en Confluence según el marco correspondiente. Los resultados dependen de los datos disponibles en tu entorno de SonarQube.

  • OWASP Top 10. Muestra los hallazgos por categoría de OWASP Top 10 para el año que selecciones. En la página de revisión de seguridad de una aplicación web, usa la macro para analizar los hallazgos agrupados por tipo de riesgo. Documentación de la macro OWASP Top 10.

  • CWE Top 25. Muestra los hallazgos asociados a la lista CWE Top 25 del año que selecciones. Al planificar las correcciones, usa la macro para identificar qué tipos de debilidades aparecen en los proyectos seleccionados. Documentación de la macro CWE Top 25.

  • OWASP ASVS. Muestra los hallazgos según el estándar OWASP Application Security Verification Standard. Añade la macro a la página de verificación de seguridad de la aplicación, junto a la lista de comprobaciones manuales del equipo. Documentación de la macro OWASP ASVS.

  • ISO 5055. Muestra los hallazgos según el estándar de medición de calidad del software ISO 5055. En una revisión de arquitectura, usa la macro para analizar los hallazgos de código y arquitectura de los servicios evaluados. Documentación de la macro ISO 5055.
