Primeros pasos

Aprende a instalar y configurar SonarQube Connector for Confluence.

Instala SonarQube Connector for Confluence

Abre la ficha de SonarQube Connector for Confluence en Atlassian Marketplace. Selecciona tu modalidad de Confluence y sigue los pasos del Marketplace para iniciar una prueba o comprar una licencia.

Configura el conector en Confluence Cloud

Para configurar conexiones con SonarQube, necesitas permisos de administración en Confluence.

Abre los ajustes de SonarQube Connector para configurar hasta cinco conexiones.

Introduce estos datos para cada conexión.

  • SonarQube Server Name. Elige el nombre que se mostrará al configurar una macro.
  • SonarQube Server URL. Introduce la URL base a la que puede acceder el conector. Una instalación local de SonarQube Server usa por defecto http://localhost:9000. Para SonarQube Cloud, usa https://sonarcloud.io.
  • Token. Para una instancia o un proyecto privado, introduce un token de usuario de SonarQube de una cuenta con acceso. Consulta la gestión de tokens en SonarQube.

HTTPS en instalaciones propias de Confluence

Si alojas Confluence en tu propia infraestructura y SonarQube Server utiliza un certificado emitido por una autoridad de certificación privada, es posible que tengas que añadir ese certificado al almacén de confianza de Confluence.

Consulta las instrucciones de Atlassian para conectar con servicios SSL.
