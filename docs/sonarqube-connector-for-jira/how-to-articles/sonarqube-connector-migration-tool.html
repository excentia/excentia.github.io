Herramienta de migración de SonarQube Connector

Si ya has migrado tu instancia de Server o Data Center a Cloud, nuestro complemento SonarQube Connector for Jira Cloud necesita la información que tenía su versión para Jira Server. Con la herramienta de migración de SonarQube Connector puedes importar todas las incidencias de SonarQube Connector for Jira con sus valores, además de la configuración del panel de SonarQube Connector de tu instancia de Jira Server.

Cómo exportar un archivo

1. Primer paso

Accede al menú de la herramienta de migración de SonarQube Connector para Server o Data Center y selecciona los proyectos cuya configuración quieres exportar (utiliza * para exportar las configuraciones y las incidencias de todos los proyectos).

Vas a exportar a un archivo información de configuración privada, como la URL de tu servidor de SonarQube o el token de Sonar. Debes ser administrador de Jira para acceder a esta herramienta.

excentia no se responsabiliza del uso malintencionado de este archivo. Utiliza esta herramienta solo si sabes lo que estás haciendo. Elimina el archivo después de la importación.

Cómo importar un archivo

2. Segundo paso

Accede al menú de la herramienta de migración de SonarQube Connector para Cloud y selecciona el archivo JSON exportado anteriormente.

3. Tercer paso

Se mostrará un informe con todos los proyectos que se van a importar. Los proyectos que existan en el archivo de migración exportado, pero no en la instancia de Jira Cloud, NO se importarán.

Haz clic en importar y espera a que finalice el proceso. ¡Ya has migrado la configuración de SonarQube Connector a Cloud!

4. Cuarto paso

Elimina el archivo JSON exportado cuando la importación haya finalizado correctamente.
