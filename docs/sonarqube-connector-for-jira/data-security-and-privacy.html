Declaración de seguridad y privacidad de los datos

excentia es partner de Atlassian desde 2009. Esta página resume cómo EXCENTIA CONSULTORIA S.L. almacena, protege y gestiona los datos de sus clientes para sus complementos de Atlassian Cloud.

Resumen

excentia es partner de Atlassian desde 2009 y cuenta con un profundo conocimiento del desarrollo de complementos para Atlassian. Esta documentación recoge la información relevante sobre la declaración de seguridad y privacidad de los datos de EXCENTIA CONSULTORIA S.L. para que nuestros clientes comprendan con claridad qué hacemos y qué no hacemos con sus datos.

De un vistazo

ÁREA

RESUMEN

Datos almacenados

Únicamente el número de identificación único de los productos de Atlassian Cloud y un token de SonarQube revocable.

Información personal

No almacenamos información personal, como nombres, direcciones de correo electrónico o direcciones postales.

Ubicación

Los datos se almacenan en un servidor privado situado en Francia.

Copias de seguridad

Las copias de seguridad se almacenan de forma segura, se crean al menos una vez al día y se conservan durante al menos un mes.

Conservación

La información de la cuenta se conserva durante 30 días tras desinstalar el complemento y, después, se elimina de forma permanente.

Contacto de seguridad

Las vulnerabilidades o los problemas de seguridad pueden comunicarse a security@excentia.es.

Condiciones y ubicación del almacenamiento de datos

Esta sección explica dónde almacena nuestra aplicación los datos de los clientes y cuál es su ubicación física para cumplir la legislación local.

Principio de almacenamiento: solo almacenamos los datos mínimos necesarios para que funcione el complemento.

  • excentia utiliza un servidor privado situado en Francia.

  • No almacenamos información personal, como nombres, direcciones de correo electrónico o direcciones postales.

  • Solo almacenamos el número de identificación único de tus productos de Atlassian Cloud.

  • excentia no almacena contraseñas de usuario de los productos de Atlassian Cloud, ni en bases de datos ni en archivos.

  • excentia almacena un token de autenticación creado en el servidor de SonarQube que el usuario puede revocar en cualquier momento.

  • Consulta la documentación del producto para obtener más información.

Copias de seguridad

Esta sección explica nuestra política de copias de seguridad y recuperación de los datos de los clientes.

  • Las copias de seguridad se almacenan de forma segura; no es posible acceder a ellas sin autorización.

  • Realizamos copias de seguridad al menos una vez al día y las conservamos durante al menos un mes.

  • Consulta la documentación del producto para obtener más información.

Eliminación de cuentas y conservación de datos

Esta sección explica cómo puede un cliente cerrar una cuenta y eliminar por completo sus datos de nuestro servicio.

  • Las cuentas de los clientes pueden eliminarse en cualquier momento desinstalando el complemento del producto Cloud.

  • excentia conserva la información de la cuenta del cliente durante 30 días. Transcurrido ese periodo, la información de la cuenta se elimina de forma irreversible.

  • Consulta la documentación del producto para obtener más información.

Seguridad de la aplicación y de la infraestructura

Esta sección explica las medidas de seguridad que hemos adoptado en nuestra aplicación y nuestra infraestructura.

  • El equipo de soporte de excentia accede a los datos del complemento únicamente para supervisar el estado de la aplicación, realizar tareas de mantenimiento del sistema o de la aplicación y prestar el soporte solicitado por el cliente.

  • Solo los empleados autorizados de excentia tienen acceso a los datos del servidor.

  • Los clientes son responsables de mantener la seguridad de sus credenciales de acceso a Confluence y Jira Cloud.

  • La comunicación entre los productos Cloud y el servidor del complemento se realiza mediante peticiones web. Todas las peticiones web están firmadas digitalmente, autenticadas y autorizadas.

  • Solo se puede acceder al servidor del complemento mediante protocolos seguros como HTTPS.

  • Consulta la documentación del producto para obtener más información.

Comunicación de incidentes de seguridad

Esta sección explica cómo y en qué circunstancias notificamos a los clientes las brechas de seguridad o vulnerabilidades, y cómo deben comunicar los usuarios o investigadores de seguridad las vulnerabilidades que encuentren en nuestro complemento.

  • Las brechas de seguridad o vulnerabilidades, junto con la solución propuesta, se publican en nuestro sitio web.

  • Los clientes pueden comunicar brechas de seguridad o vulnerabilidades a través de la dirección de correo electrónico security@excentia.es.

  • Consulta la documentación del producto para obtener más información.

Privacidad

Los datos recopilados durante el uso de nuestro complemento no se compartirán con terceros, salvo cuando lo exija la ley.
