En excentia seguimos ampliando **nuestras soluciones para Jira Cloud** con el lanzamiento de **Latest Comment Field for Jira**, una nueva aplicación disponible en el Atlassian Marketplace que permite **visualizar el último comentario de cada Work Item** directamente en los resultados de búsqueda JQL.

Una funcionalidad sencilla, pero especialmente útil para los equipos que necesitan **realizar un seguimiento de sus tareas, consultar actualizaciones y conocer el estado** de diferentes Work Items sin tener que abrirlos individualmente.

<h2>¿Cómo visualizar el último comentario de varios Work Items en Jira?</h2>

Cuando trabajamos con **múltiples Work Items en Jira**, los comentarios son una fuente importante de información. En ellos encontramos actualizaciones de estado, decisiones, respuestas de compañeros y detalles sobre el progreso de las tareas. Sin embargo, **consultar el comentario más reciente** de diferentes Work Items puede resultar poco práctico si tenemos que acceder a cada uno por separado.

Latest Comment Field for Jira resuelve esta necesidad mediante **un campo personalizado de solo lectura** que muestra el último comentario registrado en cada Work Item. Este campo puede añadirse como **una columna adicional** a los resultados de búsqueda de Jira, permitiendo consultar los comentarios más recientes de múltiples Work Items desde una única vista.

<h2>¿Qué es Latest Comment Field for Jira y cómo funciona?</h2>

Latest Comment Field for Jira es una aplicación desarrollada por excentia para Jira Cloud que permite **almacenar y mostrar automáticamente el comentario más reciente** de cada Work Item en un campo personalizado denominado Latest Comment.

Su funcionamiento se basa en tres características principales:

1. **Visualiza los últimos comentarios directamente en las búsquedas JQL**: La aplicación incorpora un campo personalizado que puedes añadir como columna en los resultados de búsqueda de Jira. Así, cuando realizas una búsqueda mediante JQL (Jira Query Language), puedes consultar el último comentario de cada Work Item junto al resto de información relevante, como el estado, la prioridad o la persona asignada. La principal ventaja es que puedes revisar los últimos comentarios de varios Work Items de un vistazo, sin necesidad de abrir cada uno de ellos.

2. **Mantén los comentarios actualizados automáticamente**: El campo Latest Comment se sincroniza automáticamente con los cambios realizados en los comentarios de Jira. Cuando un usuario añade un nuevo comentario o modifica el comentario más reciente de un Work Item, la aplicación actualiza el contenido del campo personalizado. También contempla la eliminación de comentarios para mantener sincronizada la información mostrada. Además, al tratarse de un campo de solo lectura, su contenido no puede modificarse manualmente.

3. **Recupera los últimos comentarios de los Work Items existentes**: Latest Comment Field for Jira incorpora un panel de administración que permite recorrer los Work Items existentes y completar el campo con su último comentario disponible. Este proceso de actualización inicial permite aprovechar la funcionalidad tanto en los nuevos Work Items como en los que ya forman parte de los proyectos de Jira. La interfaz de administración también ofrece información sobre el progreso del proceso y opciones para reintentar operaciones fallidas.

<h2>¿Cómo configurar Latest Comment Field for Jira?</h2>

La configuración es sencilla y se realiza desde Jira Cloud.

1 - [Instala desde aquí](https://marketplace.atlassian.com/apps/1751502951/latest-comment-field-for-jira?utm_source=blog&utm_medium=web+excentia&utm_campaign=Comunicacion+Marketplace) Latest Comment Field for Jira desde el Atlassian Marketplace.

2 - Accede a la configuración del espacio de tu proyecto en Jira.

3 - Entra en la sección de campos (Fields).

4 - Selecciona la opción para añadir un campo (Add field).

5 - Busca el campo Latest Comment y añádelo al espacio.

6 - Incorpora el campo como columna en los resultados de búsqueda de Jira.

Si necesitas visualizar los últimos comentarios de Work Items creados anteriormente, puedes utilizar el panel de administración de la aplicación para realizar la actualización inicial.

Descubre **Latest Comment Field for Jira** y empieza a visualizar las últimas actualizaciones de tus proyectos desde una única vista.

<h2>Preguntas frecuentes sobre Latest Comment Field for Jira</h2>

**¿Se puede visualizar el último comentario de un Work Item en una búsqueda JQL?**

Sí. Con Latest Comment Field for Jira puedes añadir el campo personalizado Latest Comment como columna en los resultados de búsqueda de Jira y consultar el comentario más reciente de cada Work Item.

**¿El último comentario se actualiza automáticamente?**

Sí. La aplicación actualiza el campo cuando se añade un nuevo comentario o se modifica el comentario más reciente. También sincroniza los cambios cuando se eliminan comentarios.

**¿Puedo consultar los últimos comentarios de Work Items antiguos?**

Sí. La aplicación incorpora una sección de administración que permite actualizar el campo de los Work Items que ya existían antes de su instalación.

**¿Puedo modificar manualmente el campo Latest Comment?**

No. Es un campo personalizado de solo lectura cuyo contenido se gestiona automáticamente mediante la aplicación.

**¿Latest Comment Field for Jira está disponible para Jira Cloud?**

Sí. La aplicación está disponible para Jira Cloud a través del Atlassian Marketplace.
