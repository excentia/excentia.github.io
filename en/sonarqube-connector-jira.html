SonarQube Connector for Jira Features

Bring code quality insights and work management together in Jira. The connector helps developers, quality assurance teams, and engineering managers view SonarQube results and use them to plan software improvements.

View SonarQube Metrics and Quality Gates in Jira

View Quality Gate status, code quality metrics, and details of issues detected in your SonarQube Server or SonarQube Cloud projects.

Access code quality and security information directly in Jira to identify areas that need attention and decide what to tackle next.


Generate SonarQube PDF Reports from Jira

Export results from one or more SonarQube projects to a PDF report that you can share with your team, project managers, or customers.

The connector supports five report types: General Quality Report, CWE Top 25, OWASP Top 10, OWASP ASVS, and ISO 5055.

Use these reports to communicate project status and provide evidence for code quality and security reviews.

Learn how to generate and download SonarQube PDF reports from Jira with our step-by-step tutorial.

Create Jira Work Items from SonarQube Issues

Create a Jira work item with one click from an issue detected by SonarQube. Bring findings into the Jira project where your team manages its work so you can prioritize fixes.

This feature makes it easier to track fixes and eliminates the need to manually copy information between tools.



Link Multiple SonarQube Projects to Jira

Use Project Portfolio to link multiple SonarQube projects to a single Jira project.

This feature is useful when your team manages several software components within the same Jira project and needs to view their code quality results in one place.

Frequently asked questions

Does the connector work with SonarQube Server and SonarQube Cloud?

Yes. SonarQube Connector for Jira lets you integrate both SonarQube Server and SonarQube Cloud projects with Jira.

Can I download SonarQube PDF reports from Jira?

Yes. The connector generates PDF reports with your project results, including a General Quality Report and reports based on CWE Top 25, OWASP Top 10, OWASP ASVS, and ISO 5055.

Can I work with multiple SonarQube projects?

Yes. Project Portfolio lets you link multiple SonarQube projects to one Jira project. You can also generate PDF reports for one or more projects.

Are Jira work items created automatically?

No. Work item creation is initiated by the user: you can create a Jira work item with one click from a SonarQube finding.
