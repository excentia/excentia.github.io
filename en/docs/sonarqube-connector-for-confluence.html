SonarQube Connector for Confluence

Bring SonarQube Server and SonarQube Cloud results into your Confluence pages. Review code quality and security where your team keeps its documentation.

SonarQube Connector for Confluence is an app developed by excentia that lets development teams share SonarQube results in Confluence using macros and badges.

Key capabilities

  • View code quality and security metrics.
  • Check Quality Gate status and conditions.
  • Consolidate multiple projects into a single view.
  • View bugs, vulnerabilities, code smells, and Security Hotspots, identify critical or blocker issues, and filter issues by author or project.
  • Insert a dynamic badge to highlight the value of a specific metric, such as code coverage, within a page.
  • Display analysis results using macros for OWASP Top 10, OWASP ASVS, CWE Top 25, and ISO 5055.
  • Display the active rules in a SonarQube quality profile, including their severity, language, type, and links to the rules.
