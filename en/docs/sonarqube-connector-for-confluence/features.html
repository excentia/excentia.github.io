Features

SonarQube Connector for Confluence displays code quality and security results from SonarQube Server or SonarQube Cloud on your Confluence pages. Use it to review a project’s Quality Gate before a release, track several components in one view, or add a code coverage badge to a component page.

Check the Quality Gate before a release

Display the Quality Gate status and its conditions on a Confluence page. During a release review, use the conditions to see what needs attention when a project fails its Quality Gate.

Add a project dashboard to a Confluence page

Use the SonarQube Connector Macro to display a project’s reliability, security and maintainability ratings alongside measures such as code coverage, duplication and technical debt. Select a configured SonarQube connection and enter the project key in Resource Key. Use Custom metrics to add available measures by metric key. When the macro is configured for a single project, you can also specify a branch.

See the macro configuration guide.

Track multiple SonarQube projects in one view

Enter several project keys in Resource Key, separated by commas, or use Tags to select projects by their SonarQube tags. The macro displays aggregate measures and ratings, with the Quality Gate status and last analysis date for each project. You can also select an existing Enterprise portfolio by name where supported.

Read about Multiple project keys · Tags and portfolio configuration.

Display a SonarQube metric as a badge

Use the SonarQube Connector Badge macro when a page needs a single metric. Select the SonarQube connection, enter the project key and set Metric Key to the measure you want to display. The badge macro also supports aggregating a metric across multiple projects.

For example, enter sonarlint-visualstudio in Resource Key and coverage in Metric Key. Place the badge near the component summary so readers can see its code coverage as soon as they open the page. Badge configuration · Badge examples

Review issues and security findings

Show a breakdown of SonarQube issues

Use Issue Breakdown to display a summary of issues for one or more projects. This gives the team a shared view to review alongside project documentation.

Display security reports

Use these macros to bring SonarQube findings into a Confluence review page under the relevant reporting framework. The results depend on the data available in your SonarQube environment.

  • OWASP Top 10. Display findings by OWASP Top 10 category for the year you select. On a web application’s security review page, use the macro to discuss findings grouped by risk category. OWASP Top 10 macro documentation

  • CWE Top 25. Display findings mapped to the CWE Top 25 list for the year you select. On a remediation planning page, use the macro to identify which types of software weakness appear across the selected projects. CWE Top 25 macro documentation

  • OWASP ASVS. Display findings organised by the OWASP Application Security Verification Standard. On an application security verification page, add the macro alongside the team’s manual review checklist. OWASP ASVS macro documentation

  • ISO 5055. Display findings organised by the ISO 5055 software quality measurement standard. On an architecture review page, use the macro to discuss code and architecture findings across the services under review. ISO 5055 macro documentation
