Installation and setup

Does SonarQube Connector for Confluence work with SonarQube Server and SonarQube Cloud?

Yes. The connector can display analysis results from both SonarQube Server and SonarQube Cloud. A Confluence administrator configures the connection in the app settings. For SonarQube Cloud, use https://sonarcloud.io as the base URL.

Where do I install the connector, and which Confluence versions are supported?

Install the app in Confluence from Atlassian Marketplace. Select your Confluence deployment in the listing and check the compatible versions before installing or upgrading.

Where do I find my SonarQube project key?

Look for the project key in your SonarQube project dashboard or in the analysis configuration, where it is set as sonar.projectKey. Copy it into the Resource Key field of the Confluence macro. Macro configuration

Connections and troubleshooting

Can I display metrics or badges from a private SonarQube project?

Configure the SonarQube connection with a user token from an account that can access the private project. Then select that connection and enter the project key in the macro. Before sharing the Confluence page, check its restrictions and verify what a reader can see in your deployment.

Can Confluence Cloud connect to SonarQube Server behind a firewall?

The connector needs a network route to the SonarQube Server URL you configure. If your server is accessible only from a private network, ask excentia support to confirm the connectivity requirements for your deployment before changing firewall rules.

Why is my SonarQube macro empty or showing an error?

First, open the same project in SonarQube and confirm that it has a completed analysis. Then check the connection selected in the macro, the base URL and the project key. For a private project, verify that the user token is valid and that its account can access the project. If several macros fail for the same connection, check whether the connector can reach the SonarQube URL.

Why is my code coverage badge missing or showing 0%?

Check the coverage value for the same project in SonarQube first. If coverage is missing or unexpectedly low there, verify that your build generates a coverage report and that the analysis imports it. If SonarQube shows the expected value, check that the badge uses the correct connection, project key and Metric Key coverage.

Viewing SonarQube results in Confluence

How do I add a SonarQube dashboard or a coverage badge to a Confluence page?

Edit the Confluence page and insert the SonarQube Connector Macro for a project dashboard or SonarQube Connector Badge for a single metric. Select the configured SonarQube connection and enter the project key. For a coverage badge, enter coverage in Metric Key.

Can I see why a Quality Gate failed without leaving Confluence?

Yes. The connector can display the Quality Gate status and its conditions in a Confluence page. Use the conditions to see which threshold the analysis failed to meet, such as minimum coverage on new code.

Can I show several SonarQube projects in a single Confluence page?

Yes. In the dashboard macro, enter comma-separated project keys in Resource Key or select projects using their SonarQube tags in Tags. The combined view shows aggregate measures and ratings, plus the Quality Gate status and last analysis date for each project. Multiple project keys.

Can I display security findings by OWASP or CWE in Confluence?

Yes. The OWASP Top 10 and CWE Top 25 macros display findings for the configured projects using the reporting year you select. The results depend on the data available in your SonarQube environment. OWASP Top 10 macro · CWE Top 25 macro

Tip: if an answer does not resolve your case, first review the connection configuration and then contact support with the URL, connector edition and affected project keys.
