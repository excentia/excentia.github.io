FAQs

This section brings together common questions about SonarQube Connector for Jira and helps you quickly identify what to review in each case.

Initial setup

1. Can I use the connector with SonarQube Server and SonarQube Cloud?

Yes. SonarQube Connector for Jira lets you view information from SonarQube Server and SonarQube Cloud projects in Jira. You need to configure the connection for the service you use.

2. Where do I need to install the connector?

It is installed in Jira from Atlassian Marketplace. Select the option that matches your environment and check compatibility with your Jira version.

3. I have configured the connection, but the results do not appear. What should I check?

As an initial check, review the SonarQube URL, token and configured project key. If the problem continues, also check the connectivity between the connector and SonarQube. These are the first points worth ruling out for this type of query.

Connection and projects

4. Can a firewall prevent the connector from working?

Yes. There is a resolved case in Atlassian Community where it was necessary to allow traffic from the connector server. If your SonarQube has access restrictions, confirm the current network requirements with support.

5. Where can I find the SonarQube project key?

You can get it from the SonarQube project panel or from its analysis parameters. You must use the project key in the Resource ID field, or the equivalent field in your version.

6. Can I link several SonarQube projects to one Jira project?

Yes. The documented configuration allows you to enter several project keys separated by commas. The connector groups their metrics into a single view.

Viewing results in Jira

7. What SonarQube information can I view in Jira?

You can view quality metrics, Quality Gate status, vulnerabilities, Security Hotspots and technical debt, as well as access the issue breakdown for linked projects.

8. Can I display the results on a Jira dashboard?

The connector documentation includes a gadget configuration for displaying information from one or more projects. Check which gadgets are available in the edition and version you have installed.

9. How do I create a Jira work item from SonarQube results?

Use the creation button located in the SonarQube rule row. The connector generates the item with the rule name and links to the corresponding issues.

10. Why does a warning appear saying that the issue already exists?

The connector checks whether the rule already has an associated issue and displays a warning to avoid creating another one for the same findings.

11. Where can I find the created work item?

Its link appears in the same SonarQube rule row. According to the documentation, it stops being displayed if the issue is deleted or resolved.

12. Why does the SonarQube tab not appear in a manually created issue?

That tab is shown in issues created through the connector. A manually created issue does not automatically establish the relationship with SonarQube findings.

13. How can I download a quality and security report in PDF?

Open the linked Jira project, go to the connector’s Overview panel and use the SonarQube Evidence Report download option.

Tip: if an answer does not resolve your case, first review the connection configuration and then contact support with the URL, connector edition and affected project keys.
