Integrate SonarQube Server or SonarQube Cloud with Confluence. Add macros to your pages to review Quality Gates, coverage, and technical debt for one or more projects alongside your documentation.

What can you see from SonarQube in Confluence?

Macros show Quality Gate status, code quality metrics, and security findings for the projects you select.

Check the Quality Gate before a release

See whether a project meets its Quality Gate conditions. If it fails, check which thresholds it missed directly in Confluence, such as minimum coverage on new code.

View multiple projects in one place

Group projects by key or tag to compare coverage, duplication, reliability, and security. The view shows aggregate metrics and the status of each project.

Highlight code coverage with a badge

To show a single metric, use the SonarQube Connector Badge macro. For example, place the coverage percentage next to the component summary.

Explore issues and security findings

Review bugs, vulnerabilities, and Security Hotspots alongside your project documentation. See the full list of macros in Connector features.

How do you get started with SonarQube in Confluence?

To get started in Confluence Cloud, install the app from Atlassian Marketplace, configure a connection to SonarQube, and add a macro to a page. You need Confluence administrator permissions to configure the connection.
